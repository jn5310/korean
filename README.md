# 지문·문제 재구성 스튜디오

PDF(텍스트/스캔본)에서 지문과 문제를 추출하고, Gemini API 로 난이도(1~5단계)를 자동 분류한 뒤,
직접 편집하여 **각 지문을 새 페이지에서 시작하는** 교재와 맞춤형 시험지를 PDF 로 출판하는 PyQt6 데스크톱 프로그램입니다.

## 가장 쉬운 실행 방법 (Windows)

명령 프롬프트에 아무것도 입력할 필요가 없습니다.

1. GitHub의 **Code → Download ZIP**으로 받은 파일의 압축을 풉니다.
2. 압축을 푼 폴더에서 **`실행하기.bat`**를 더블클릭합니다.
3. 처음 한 번은 필요한 프로그램을 자동으로 설치합니다. 설치가 끝나면 앱이 자동으로 열립니다.
4. 다음부터는 **`실행하기.bat`**만 더블클릭하면 바로 실행됩니다.

> Windows에서 보호 경고가 나오면 **추가 정보 → 실행**을 선택하세요.
> Python이 없으면 실행 파일이 공식 설치 페이지를 자동으로 엽니다. Python 설치 화면에서는
> **Add python.exe to PATH**를 선택하고, 설치 후 `실행하기.bat`를 다시 더블클릭하세요.

## macOS·Linux 또는 수동 실행

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate   /   macOS·Linux: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

- Python 3.10 이상
- Gemini API Key: [Google AI Studio](https://aistudio.google.com/apikey) 에서 무료 발급 → 앱의 **설정(Ctrl+,)** 에 입력
  (또는 환경변수 `GEMINI_API_KEY`)
- 텍스트 PDF는 추가 설치 없이 읽습니다. 스캔본은 Tesseract가 있으면 로컬 OCR을 사용하고,
  없더라도 API Key가 설정되어 있으면 13MB 이하 PDF를 Gemini 문서 비전으로 직접 분석합니다.
- 로컬 스캔 OCR을 사용하려면 [Tesseract](https://github.com/tesseract-ocr/tesseract)와 한국어 데이터(`kor`)를 설치하고 설정에서 경로를 지정하세요.
- Windows에서 앱이 열리지 않으면 프로젝트 폴더의 `실행오류.txt`를 확인하세요.

## PDF 분석 사용법

1. 대시보드에서 PDF를 끌어다 놓거나 **PDF 추가…**로 선택합니다.
2. **분석 시작**을 누릅니다. 같은 화면에서 페이지 추출 → OCR → 지문/오지선다 복원 → Gemini 교차 검토가 순서대로 실행됩니다.
3. 완료 창에서 성공·실패 파일, OCR 페이지, AI 사용 여부와 상세 경고를 확인합니다.
4. 성공하면 결과가 자동 저장되고 **편집·검수** 화면으로 이동합니다.

분석기는 PDF의 글자 하나하나의 위치를 읽어 원문을 복원합니다.

- **띄어쓰기**: PDF에 실제 공백 글자가 있으면 그 공백만 사용하고, 양쪽 정렬로 벌어진 글자 간격은
  띄어쓰기로 보지 않습니다. 공백 글자가 없는 PDF는 줄마다 기준 간격을 계산하고, 애매한 곳은 같은
  문서에서 확실하게 판정된 낱말 통계로 결정합니다.
- **줄바꿈**: PDF의 자동 줄바꿈(`다르` / `게`)은 이어 붙이고, 문단·문항·선택지·시 행 구분은 유지합니다.
  단이나 페이지를 넘어 이어지는 문단도 연결합니다.
- **겹친 글자**: 같은 글자를 겹쳐 찍어 굵게 보이게 만든 PDF(`222222`, `윗윗윗글글글`)는 한 글자로 합치고
  굵게 서식으로 표시합니다.
- **2단 편집**: 단 사이 여백을 찾아 왼쪽 단 → 오른쪽 단 순서로 읽고, 반복 머리말·쪽 번호는 제거합니다.
- **<보기>·표·그림**: `<보기>` 상자는 라벨까지 포함해 원본 그대로 잘라낸 **그림으로만** 보여 주고, 발문에는
  글자를 중복해 넣지 않습니다. 그림 속 글은 숨겨 두었다가 AI 난이도 분석에만 사용합니다.

`[1~3] 다음 글을 읽고 물음에 답하시오` 같은 범위와 문항 번호, ①~⑤를 결합해 지문과 문제를 묶습니다.
Gemini가 전체 문맥과 시각적 PDF를 다시 검토하되, 원문 일치도와 문항 수를 로컬 결과와 비교해 더 완전한 구조만 채택합니다.
API 오류가 발생해도 로컬 추출 결과는 유지됩니다.

### 이전에 분석한 PDF를 다시 분석할 때

이전 버전에서 분석해 띄어쓰기가 틀리거나 글자가 겹쳐 있던 PDF는 **같은 PDF를 다시 분석**하세요.
분석이 끝나면 **기존 결과 교체**를 선택할 수 있습니다.

- 교체하면 새로 복원한 지문·문제로 바뀝니다.
- 직접 입력한 정답·해설, 직접 정한 난이도·유형·제목, 직접 추가한 그림은 **번호와 선택지가 같은 새 문항**으로 옮겨지고,
  시험지에 담아 둔 지문은 그 문항들이 들어간 새 지문으로 자동 연결됩니다.
- 옮길 곳을 확실히 찾지 못한 입력이 있거나 이 버전에서 직접 고친 이전 지문은 지우지 않고 `[이전 분석]` 제목으로 보관합니다.
  새 결과와 짝이 없는 이전 지문도 입력한 내용·시험지 구성이 있거나 이전 버전에서 고쳤을 수 있으면 그대로 남습니다.
- 교체 전에 보관·유지될 지문 수를 확인 창에서 미리 보여 줍니다.
- **기존 결과 유지**를 누르면 라이브러리는 그대로 두고 그 파일의 새 결과는 추가하지 않습니다.
사용할 수 없어진 Gemini 모델이 설정되어 있으면 API 모델 목록에서 실제 현재 요청을 처리할 수 있는 모델을 찾아 자동 전환·저장합니다.

## 서식·그림 검수와 편집

- 텍스트 PDF의 글꼴 정보를 분석해 **굵게, 기울임, 밑줄, 글자색**을 지문·발문·각 선택지에 보존합니다.
- `<보기>` 상자, 표, 래스터 그림, 벡터 도표를 원본 위치 그대로 잘라 지문·발문·선택지에 붙입니다.
  그림은 원본 PDF에서 차지하던 크기에 맞춰 미리보기와 출판 PDF에 표시됩니다.
- OCR 페이지는 검수용 원본 페이지 이미지도 보존합니다.
- **편집·검수** 화면의 서식 도구에서 굵게·밑줄·색상을 바꾸거나 그림을 추가·삭제할 수 있습니다.
- 오른쪽 미리보기에는 저장된 서식과 문제별 그림이 반영됩니다. OCR만으로는 원래 글꼴 속성을 판별할 수 없으므로 스캔본은 원본 페이지 그림과 함께 확인하세요.

## 시험지 PDF 출판

1. **시험지 생성**에서 원하는 지문을 담고 순서를 정합니다.
2. **PDF 내보내기**를 누르고 제목, 글자 크기, 정답·해설 포함 여부와 선택 글꼴을 정합니다.
3. 각 지문은 새 페이지에서 시작하고, 긴 지문·문제는 잘리지 않고 다음 페이지로 이어집니다.
4. 굵게·색상·밑줄과 지문/발문/선택지 그림이 최종 PDF에도 출력됩니다.

이미지가 포함된 라이브러리를 옮길 때는 파일 메뉴의 **라이브러리 백업 내보내기 (.koreanlib)**를 사용하세요. JSON과 모든 참조 그림이 한 파일에 함께 저장됩니다.

> PRD 에는 `google-generativeai` 로 되어 있으나 해당 패키지는 지원 종료(deprecated)되어,
> Google 이 권장하는 후속 SDK 인 `google-genai` 를 사용합니다.

## 프로젝트 구조

```
main.py                     # 진입점
실행하기.bat                # Windows 원클릭 설치·실행
windows_launcher.pyw        # Windows 오류 안내 GUI 실행기
app/
├── config.py               # 설정(JSON) · 난이도/유형 상수
├── assets.py               # 검증된 이미지 자산 저장·해시 중복 제거
├── models.py               # Passage 1:N Question, 리치 서식·이미지, ExamSet, Library
├── storage.py              # JSON 저장 및 이미지 포함 .koreanlib 백업
├── services/               # ── Qt 비의존 비즈니스 로직
│   ├── analysis_pipeline.py # PDF→OCR→구조→AI 통합·부분 성공·중복 방지
│   ├── pdf_parser.py       # 글자 좌표·서식·그림 추출 + 품질 판정 + 스캔 OCR
│   ├── pdf_text_layout.py  # 2단 읽기 순서·띄어쓰기·문단 이어붙이기·겹친 글자 정리
│   ├── pdf_regions.py      # <보기> 상자·표·그림 영역 판정, 밑줄 탐지
│   ├── structure_parser.py # 지문 뒤 오지선다 문제 규칙 기반 복원
│   ├── library_merge.py    # 같은 PDF 재분석 시 기존 지문 교체·시험지 재연결
│   ├── document_analyzer.py# Gemini 문서 구조 교차 검토·PDF 비전
│   ├── difficulty.py       # AI 난이도(1~5)·유형 분석
│   ├── gemini_client.py    # Gemini 연동·사용 가능 모델 자동 복구
│   ├── rich_content.py     # 굵게·색상·밑줄·그림을 지문/발문/선택지에 투영
│   └── pdf_exporter.py     # 리치 서식·그림 포함 실제 PDF 출판
└── ui/                     # ── PyQt6 화면
    ├── main_window.py      # 내비게이션 · 메뉴 · 상태표시줄
    ├── dashboard.py        # 메인: PDF 업로드(드래그 앤 드롭) · 분석 시작 · API 상태 · 현황
    ├── settings_dialog.py  # API Key · 모델 · 연결 테스트 · OCR 설정
    ├── editor_view.py      # 편집·검수: 목록 | 지문/문제 편집 | 미리보기
    ├── test_creator.py     # 시험지 생성: 조건별 탐색기 | 작업 공간(드래그 정렬)
    ├── state.py            # 공유 상태(설정/라이브러리/스레드 풀) · 시그널
    ├── workers.py          # QThreadPool 백그라운드 작업 (GUI 멈춤 방지)
    ├── widgets.py, styles.py
```

데이터(설정·라이브러리)는 OS 사용자 데이터 폴더에 저장됩니다
(Windows `%APPDATA%\KoreanStudio`, macOS `~/Library/Application Support/KoreanStudio`,
Linux `~/.local/share/korean-studio`). `STUDIO_DATA_DIR` 환경변수로 변경할 수 있습니다.
